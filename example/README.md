# talkaNote SDK example

A small app that scans for cards, connects, shows the card's status, lists
recordings, downloads and deletes them, and records with live audio.

```sh
flutter run            # pick your phone or desktop
```

Downloads are saved to the app's documents folder.

`integration_test/card_test.dart` runs the SDK against a real card; see the
main [README](../README.md#development).
